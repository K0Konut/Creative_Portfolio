# COMP-213 — Principe de travail

Plugin local de Figma Desktop. Importer [`manifest.json`](./manifest.json) via **Plugins → Development → Import plugin from manifest**, puis lancer **Creative Portfolio — Work Principle Builder**.

La page `02.22 — Work Principle` contient le set `Work principle` avec deux dispositions : `Layout=Wide|Compact`. Le composant est statique et expose trois propriétés : `Title`, `Body` et `Show accent`. L'accent rose est uniquement décoratif ; le titre et l'explication restent suffisants lorsqu'il est masqué. Les références FR/EN, l'exemple sans accent et la largeur compacte de 320 px servent à vérifier le retour à la ligne et la hiérarchie.

Les formulations de la planche sont des placeholders de revue. Elles ne décrivent pas encore la manière de travailler réelle de Costa et ne doivent pas être publiées. Le contenu final devra exprimer une idée concrète, courte et appuyée par un exemple vérifiable. Le composant ne devient pas une carte cliquable sans destination réelle et sa hauteur reste déterminée par son contenu.

Le plugin synchronise l'approbation de première passe de `COMP-210` dans son set et le sommaire Figma. Une relance préserve `COMP-213` et ses instances.
