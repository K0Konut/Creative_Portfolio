# COMP-207 — Élément de stack

Plugin local de Figma Desktop. Importer [`manifest.json`](./manifest.json) via **Plugins → Development → Import plugin from manifest**, puis lancer **Creative Portfolio — Stack Item Builder**.

La page `02.17 — Stack Item` contient un set `Stack item` de deux formes structurelles : `Format=Summary` pour le bandeau statique et `Format=Detail` pour les listes. `Name` est une propriété texte obligatoire. La forme détaillée expose `Context` et `Show context` ; ce texte est facultatif et ne doit être publié que s'il est documenté. Des instances de revue FR/EN et une référence détaillée de largeur compacte montrent les retours à la ligne sans créer de variantes linguistiques.

Les libellés « Nom de technologie » et « Technology name » sont des placeholders de revue. Aucun nom de technologie, niveau de maîtrise, catégorie ou logo n'est attribué à Costa ou à SideQuest. Un logo officiel pourra être ajouté plus tard, toujours accompagné du nom textuel. Le composant reste non interactif : pas de lien, filtre ou état hover. `COMP-208` et `COMP-209` organiseront ces éléments après validation de la structure et réception des contenus.

Le plugin synchronise l'approbation individuelle de `COMP-205 Carrousel` dans son set et le sommaire Figma. Une relance préserve `COMP-207` et ses instances.

**Statut :** première passe générée, capture revue et `COMP-207` validé explicitement par Costa le 2026-09-22. Les deux formats, les exemples FR/EN et le retour à la ligne à 280 px sont lisibles sans chevauchement apparent. Le composant reste inclus dans la seconde passe globale.
