# COMP-211 — Entrée de timeline

Plugin local de Figma Desktop. Importer [`manifest.json`](./manifest.json) via **Plugins → Development → Import plugin from manifest**, puis lancer **Creative Portfolio — Timeline Entry Builder**.

La page `02.20 — Timeline Entry` contient le set `Timeline entry` : `Category=Education|Experience` × `Layout=Wide|Compact` (4 variantes). Chaque entrée garde ensemble catégorie, période et titre. L'organisation/contexte et la description sont éditables et facultatifs via `Show organization` et `Show description`. Les références à 900 et 320 px ainsi que les exemples FR/EN servent à vérifier le retour à la ligne et l'ordre de lecture.

Les libellés, périodes et descriptions de la planche sont des placeholders de revue : aucun établissement, emploi ou date n'est attribué à Costa. Une entrée sans période ou titre vérifié reste une dépendance éditoriale ; ne pas publier les textes « à renseigner ». Le composant est statique, sans accordéon, lien automatique ou alternance gauche-droite. La future `COMP-210 Timeline du parcours` ordonnera les entrées du plus récent au plus ancien dans une liste sémantique.

Le plugin synchronise l'approbation individuelle de `COMP-209` dans son set et le sommaire Figma. Une relance préserve `COMP-211` et ses instances.

**Statut :** première passe générée, capture revue et `COMP-211` validé explicitement par Costa le 2026-09-22. Les quatre variantes, les exemples FR/EN, le retour à la ligne à 320 px et la référence sans champs facultatifs sont lisibles sans chevauchement apparent. Le composant reste inclus dans la seconde passe globale.
