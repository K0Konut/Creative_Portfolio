# COMP-208 — Bandeau de stacks

Plugin local de Figma Desktop. Importer [`manifest.json`](./manifest.json) via **Plugins → Development → Import plugin from manifest**, puis lancer **Creative Portfolio — Stack Band Builder**.

La page `02.18 — Stack Band` contient le set `Stack band` avec `Layout=Wide` (1120 px) et `Layout=Compact` (320 px). Les deux variantes sont statiques et réutilisent quatre instances de `COMP-207 Stack item / Summary` pour éprouver la densité. Le titre et chaque nom peuvent être modifiés ; le nombre de quatre entrées n'est qu'un exemple de revue, à adapter quand la sélection réelle sera connue. Les références FR/EN montrent les mêmes quatre positions sans créer de variante linguistique.

Le bandeau ne crée aucun lien, filtre, carrousel, défilement automatique ou commande. En compact, les éléments restent dans l'ordre et se placent sur plusieurs lignes sans défilement horizontal. Dans le futur écran, employer un titre de section et une seule liste sémantique, avec chaque technologie présente une seule fois. Les noms affichés sont des placeholders et ne sont pas des compétences attribuées à Costa. Vérifier le nombre final, les noms réels, le reflow à 320 px et le zoom 200 % lors de la composition de l'accueil.

Le plugin synchronise l'approbation individuelle de `COMP-207` dans son set et le sommaire Figma. Une relance préserve `COMP-208` et ses instances.

**Statut :** première passe générée, capture revue et `COMP-208` validé explicitement par Costa le 2026-09-22. Les dispositions étendue et compacte affichent les quatre noms de revue dans le même ordre sans chevauchement apparent. Le composant reste inclus dans la seconde passe globale.
